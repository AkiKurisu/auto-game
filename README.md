## What it does

Auto Game is a one-command CLI that lets your coding agent automate a running game. 

> Only Unity games on the Mono backend are supported today. IL2CPP and other game engines are not supported yet.

## Install

Add this repository as a plugin marketplace, then install **Auto Game**:

- **DotCraft** — open **Plugins**, select **Add marketplace** from the menu beside **Create**, and enter `AkiKurisu/auto-game`.

  ![Auto Game in DotCraft](./docs/images/dotcraft-auto-game-plugin.png)

- **Codex** — run `codex plugin marketplace add AkiKurisu/auto-game`.

  ![Auto Game in Codex](./docs/images/codex-auto-game-plugin.png)

Leave the rest to the agent:

> Set up Auto Game for me.

## Use it

Start the game, then just ask:

> Set my health to 100.
